桌面歌词

显示桌面歌词 播放时显示透明置顶歌词窗口
锁定桌面歌词 锁定后鼠标会穿透歌词；可从系统托盘或这里解锁
字体预设 从适合中文歌词显示的系统字体中选择

配色方案 方案同时确定已播放与未播放歌词颜色
桌面歌词位置 解锁后拖动歌词窗口即可自动保存

怎么用

  • 歌词窗无边框、无标题、无背景，并始终置顶。
  • 鼠标悬停在歌词上会显示控制条：上一首 / 播放暂停 / 下一首 / 锁定 / 关闭。
  • 默认锁定（鼠标穿透）；解除锁定后才能拖动窗口和点击控制条。
  • 关闭歌词后可在这里或系统托盘重新打开；关闭此设置窗口不会退出客户端。
